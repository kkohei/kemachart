# KEMA my Recipi｜施術記録アプリ

美容室で **KEMA** の施術を行う美容師さんのための、施術記録アプリです。
お客様の来店時のダメージレベル測定・KEMAメニューのレシピ・ビフォーアフター写真をスマホでかんたんに記録し、あとから自分で見返せます。友達・仲間へのSNS共有ボタンつき。

将来的には、記録したデータを本部へ共有し、**KEMAレシピ集** や **AIチャットボット** の基盤にしていくことを想定しています。その第一歩として、まずは「自分の施術を記録・見返しできる」ツールを提供します。

## 主な機能

- 📋 **施術記録** — 来店日・お客様名・メニューをまとめて記録
- 📊 **ダメージレベル測定 (KEMAチャート準拠)** — 頭部を**根元から毛先まで5セクション**に分け、各セクションを Lv.1〜5 で測定。**5⁵ = 3,125通り**にお客様を分類し、`1-2-3-4-5` のようなダメージコードで管理。施術前後の比較も可能
- 🧪 **レシピ記録** — 前処理・1剤・2剤…の工程ごとに薬剤・放置時間・メモを記録
- 📷 **ビフォーアフター写真** — カメラ/ライブラリから複数枚を保存 (端末内で自動リサイズ)
- 🔍 **見返し** — お客様名・メニュー・薬剤名で検索、ダメージレベルで絞り込み
- 📤 **SNS共有** — 端末のネイティブ共有 (写真つき) / LINE / X / Facebook
- 💾 **バックアップ** — 記録をJSONで書き出し・読み込み (機種変更やデータ移行に)
- 📱 **PWA / iOSアプリ対応** — ホーム画面に追加して利用、または Capacitor でネイティブiOSアプリ化

## iOSアプリ

[Capacitor](https://capacitorjs.com/) を統合済みで、この Web アプリを**そのままネイティブiOSアプリ**として
ビルド・App Store申請できます（UIコードは web と共通）。ビルドには **macOS + Xcode が必須**です。

```bash
npm run ios      # build → cap sync ios → Xcode で開く (要 macOS)
```

- ビルド手順・Macがない場合の選択肢 → **[docs/ios.md](docs/ios.md)**
- App Store申請ガイド（署名・TestFlight・掲載情報の日本語案・審査対策）→ **[docs/app-store.md](docs/app-store.md)**

申請に必要なプライバシーポリシーは `public/privacy.html`（公開時 `https://kkohei.github.io/kemachart/privacy.html`）に用意しています。
プライバシーマニフェスト・カメラ/写真の利用目的・輸出コンプライアンス設定などの審査対策は対応済みです。

## データの保存について

記録はすべて **お使いの端末のブラウザ内 (localStorage)** に保存されます。サーバーには送信されません。
写真も端末内で圧縮して保存するため、プライバシーに配慮しつつオフラインでも動作します。
機種変更やブラウザデータ削除に備え、右上メニューから定期的に **バックアップの書き出し** をおすすめします。

## 開発

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 本番ビルド (dist/ に出力)
npm run preview  # ビルド結果のプレビュー
npm run typecheck # 型チェック
```

### 技術構成

- [Vite](https://vitejs.dev/) + [React](https://react.dev/) + TypeScript
- 追加の状態管理・ルーティングライブラリなし (軽量なハッシュルーターを自前実装)
- データ永続化: ブラウザの `localStorage`

## GitHub Pages への公開

`main` ブランチへ push すると、GitHub Actions が自動でビルドし GitHub Pages に公開します。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定
2. `main` に push すると `https://kkohei.github.io/kemachart/` に公開されます

> ベースパスは相対パス (`base: "./"`) にしてあるため、GitHub Pages のサブパス配信・独自ドメイン・
> Capacitorネイティブアプリのいずれでも、同じビルドがそのまま動作します。
